# Sougandhika Paruchuri — Personal Portfolio

[![Live Site](https://img.shields.io/badge/Live%20Site-sougandhkp.me-6366f1?style=flat-square&logo=github)](https://sougandhhhhh.github.io)

Personal profile website showcasing my work, projects, and skills.

## Stack

- Vanilla HTML / CSS / JavaScript — no build step, deploys directly to GitHub Pages
- Hanken Grotesk font (Google Fonts)
- Glassmorphism dark design with scroll animations

## Sections

- **Hero** — intro with availability badge and stats
- **About** — background and links
- **Work** — experience timeline
- **Projects** — featured projects with links
- **Skills** — tech stack with animated bars
- **Contact** — email and GitHub

## Local Preview

Just open `index.html` in a browser — no server needed.
